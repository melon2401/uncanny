# Changelog

## 0.4.0-beta.1 — 2026-11-16

First packaged experimental portfolio release for macOS + unpacked Chrome.

- Main WaveRep G4 visual analysis with local GPU inference and disagreement abstention.
- Optional DINOv3/STALL motion research with 32-frame capture and disclosed 16-frame selection.
- One launcher, readiness checks, offline recovery and optional private sample export.
- Polished compact dark/orange/blue popup, results above advanced controls, compact result mascot.
- Model setup helper, privacy documentation, measured development results and license notices.
- 60 automated tests plus live model/endpoint checks. Not a validated production detector.

Not included: Chrome Web Store publication, phone app, audio detection, cloud service,
validated general accuracy, commercial rights to restricted models, bundled model weights.
