# Working on Uncanny

Keep changes small enough to explain and test: one bug fix, feature, or
documentation improvement per commit. Run `npm test` and `npm run check`.

For a capture bug, record the platform, Chrome version, expected behavior,
observed behavior and whether the player was paused or partly offscreen.
Do not attach private videos, session cookies, credentials or browsing history.

Future detection changes need evaluation evidence. Do not introduce random
scores, infer generation from hashtags alone, or claim unmeasured accuracy.

Suggested commit prefixes: `feat:`, `fix:`, `test:`, `docs:` and `chore:`.
